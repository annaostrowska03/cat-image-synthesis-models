# Cat Image Generation using Generative Models

## Project Overview
This project, developed as part of the **Deep Learning** course (Project III) at the **Warsaw University of Technology**, explores and evaluates various generative modeling techniques for creating realistic images of cats. The primary focus is on modeling high-dimensional data distributions, optimizing generation quality, and analyzing the structure of learned latent spaces.

## Authors
* [Anna Ostrowska](https://github.com/annaostrowska03)

## Architectures
The project implements and compares the following generative approaches:
* **Generative Adversarial Networks (GANs):** Specifically DCGAN or lightweight StyleGAN variants.
* **Denoising Diffusion Probabilistic Models (DDPM):** Utilizing state-of-the-art diffusion-based synthesis.
* **Variational Autoencoders (VAEs):** Specifically VQ-VAE to investigate discrete latent space representations.

## Dataset & Preprocessing
* **Primary Dataset:** [Cat Dataset](https://www.kaggle.com/datasets/crawford/cat-dataset).
* **Exploratory Extension:** [Dogs vs. Cats](https://www.kaggle.com/competitions/dogs-vs-cats/) to analyze class-specific feature separation.
* **Preprocessing:** Images are standardized to fixed resolutions (e.g., 64x64 or 128x128) using padding or center-cropping to maintain aspect ratios.

## Experiments
We systematically investigate the following factors:
1. **Architecture Depth:** Impact of the number of layers and latent noise vector z dimensionality.
2. **Optimization:** Testing various learning rates and Adam optimizer configurations (beta_1, beta_2).
3. **Stability:** Implementation of techniques to prevent mode collapse, such as label smoothing and gradient penalties.
4. **Dataset Complexity:** Comparing models trained on cats only versus a mixed cats and dogs dataset.

## Evaluation Metrics
Model performance is assessed through:
* **Quantitative:** Fréchet Inception Distance (FID) to measure statistical distance between real and generated distributions.
* **Qualitative:** Visual assessment of realism (e.g., anatomical correctness of ears and whiskers) and sample diversity.
* **Latent Space Interpolation:** A 10-image sequence generated by linear interpolation between two latent matrices to evaluate space continuity.
